# unsloth-llama-finetuning

The Unsloth LLaMA 3.2B model is a 4-bit quantized version of Meta's LLaMA 3, fine-tuned using Unsloth’s training pipeline. It uses a memory-efficient LoRA (Low-Rank Adaptation) adapter strategy that allows training with limited hardware while maintaining high performance. This repository is of training, improvement and deployment of a document classification system built on the fine-tuned Unsloth LLaMA 3.2B model. The system classifies OCR-generated text into four key document types: invoice, bill_of_lading, mill_certificate, and packing_list.
